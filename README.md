## 🚀 Overview

Large Language Models are stateless by default.

Every interaction starts from zero unless we design a memory system around them.

This repository explores how modern AI applications manage conversations, context, and persistent user memory using:

- **LangChain**
- **LCEL (LangChain Expression Language)**
- **Groq LLM API**
- **SQLite**
- **PostgreSQL**
- **Supabase**

The goal of this project is not just to learn LangChain APIs, but to understand the **engineering principles behind memory systems used in real-world AI assistants.**

---

# 🎯 Project Goals

This repository focuses on understanding:

✅ How LangChain represents messages  
✅ How LLM pipelines are constructed using LCEL  
✅ How conversational memory works  
✅ How multiple users are separated using sessions  
✅ How context windows are managed  
✅ How conversations are persisted using databases  
✅ How production AI systems combine multiple memory layers
